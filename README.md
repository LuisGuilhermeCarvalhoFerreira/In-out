🏨 In Out - Sistema de Gestão Hoteleira

O In Out é uma aplicação web Full-stack desenvolvida para facilitar e automatizar o processo de check-in e check-out em estabelecimentos hoteleiros. O projeto foca em oferecer uma interface moderna para o usuário e um gerenciamento robusto de dados no servidor.
🚀 Tecnologias Utilizadas
Front-end

    React.js: Biblioteca principal para construção da interface.

    JavaScript (ES6+): Lógica de programação do cliente.

    Bootstrap: Framework para garantir que o design seja totalmente responsivo.

    HTML5 & CSS3: Estrutura e estilização avançada.

Back-end

    Node.js: Ambiente de execução para o servidor.

    MySQL: Banco de dados relacional para persistência de informações (inout_db).

    JSON: Utilizado para a comunicação eficiente entre as APIs e o front-end.

🛠️ Funcionalidades

    Sistema de Autenticação: Registro e login de usuários integrados ao banco de dados.

    Gestão de Hóspedes: Interface para controle de entradas e saídas (Check-in/Check-out).

    Design Responsivo: Adaptado para visualização em computadores, tablets e smartphones.

📂 Estrutura do Projeto

O projeto está organizado de forma modular para facilitar a manutenção:

    /frontend: Contém todo o código da interface em React.

    /backend: Contém o servidor Node.js e as rotas da API.

    /database: Contém os scripts SQL para criação do banco de dados.
